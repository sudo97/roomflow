# RoomFlow

Навчальний мультитенантний SaaS-сервіс бронювання для малих готелів (Go).
Репозиторій супроводжує лабораторні роботи з дисципліни «Удосконалення процесів інженерії програмного забезпечення» (ХНТУ).

```bash
go run ./cmd/roomflow          # API на :8080
go test -cover ./...
```

API: `X-Tenant-ID` у заголовку визначає тенанта (готель).

| Метод | Шлях | Опис |
|---|---|---|
| GET | /api/rooms | номери тенанта |
| POST | /api/rooms | додати номер |
| POST | /api/bookings | створити бронювання |
| POST | /api/bookings/{id}/cancel | скасувати бронювання |
