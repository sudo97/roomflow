# ADR-0004: GitOps (ArgoCD) як єдиний спосіб змін у кластері

Статус: прийнято (ЛР11)

## Рішення
Бажаний стан кластерів описано в Git (Helm-чарт, kustomize); ArgoCD синхронізує його автоматично
з self-heal і prune; середовища генерує ApplicationSet. Ручні зміни (kubectl scale/edit) скасовуються.

## Наслідки
+ аудит змін через історію Git і PR, відтворюваність середовищ;
− екстрені зміни теж проходять через Git (потрібен швидкий шлях рецензування).
